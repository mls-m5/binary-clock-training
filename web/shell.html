Binary Clock Training

Read the lit squares and enter the time. Add up the weights in each color group: the first four bits are hours, the next six minutes, and the last six seconds.

Note: Four bits can only show hours 00–15. This exercise therefore uses times between 00:00:00 and 15:59:59. A lit square counts; an unlit square is zero.
